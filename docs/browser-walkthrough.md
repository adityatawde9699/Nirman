# Live browser verification

Start both services using README instructions. Use http://localhost:3000 at desktop (1440×1000), tablet (820×1180), and mobile (390×844) sizes.

1. Inspect the landing workflow, capability cards, disclaimer and interactive demo CTA.
2. Login as Applicant. Check the seeded dashboard, project selector, notification badge and navigation.
3. Create a manufacturing project with Maharashtra, ₹15 Cr, 120 employees and hazardous materials. Enter a six-digit PIN and valid contact email.
4. Verify 12 approvals, matched-rule explanations, computed 42-day critical path, four parallel branches and graph node inspection. Pan and zoom.
5. Upload a PDF/image as Project Report. Validate it and confirm the mock OCR provider label, 92% fixture score and employee warning.
6. Submit Pollution Control Consent and record the application ID.
7. Switch to Officer in the profile menu. Open the same application, inspect the risk factors, submitted validation, SLA, history and audit trail.
8. Raise a query. Switch to Applicant, check the notification, upload an Environmental Report and attach it to a response.
9. Switch to Officer. Schedule an inspection, then open Inspections to reschedule or complete it. Enter findings or upload a text report.
10. Record Approve or Reject with a human comment. Verify that unresolved queries and inspections prevent approval, and that an existing final decision cannot be overwritten.
11. Switch to Applicant. Track the final status. Approval should create the matching renewal obligation.
12. Navigate the compliance calendar, export the CSV schedule, inspect schemes, save a shortlist item and ask the regulatory assistant questions.
13. Switch to Admin. Toggle a rule, re-run applicant discovery to verify the effect, and inspect the audit trail.
14. Open all requested routes directly, including project and approval detail URLs. Verify role redirects, missing-entity handling, empty states and mobile navigation.
15. Inspect browser console and network responses. Check charts, CSS, graph layout, keyboard focus, dialogs, and upload error feedback.

This checklist is provided for the remaining real-browser pass. Chromium could not launch in the restricted implementation workspace. The separate Happy DOM walkthrough exercises the real React components and FastAPI requests, but does not certify layout or Next.js networking.
